# FitLog

FitLog is a simple workout planner for putting together a focused training session. Browse a small exercise library, check the details before you start, and keep today's plan manageable with a five-workout limit.

## Technologies

- Next.js (App Router)
- React and TypeScript
- Tailwind CSS and DaisyUI
- Lucide React icons
- React Toastify for notifications
- FitLog workout API for exercise data

## Key Features

1. **Workout library:** Browse exercises with useful stats such as equipment, duration, calories, and rating.
2. **Exercise details:** Check muscle groups, difficulty, sets, reps, and step-by-step instructions before choosing a workout.
3. **Daily plan:** Add workouts to a plan with a limit of five exercises.
4. **Saved workouts:** Keep a separate in-app list of exercises you may want to use later.
5. **Plan controls:** Mark exercises as done, remove them from your plan, and sort the list to suit your session.

## Run Locally

You'll need Node.js and npm installed.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. To create a production build, run `npm run build`.
